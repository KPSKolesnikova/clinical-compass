# Видеодемонстрация Клинического Компаса

[Смотреть или скачать MP4](clinical-compass-demo.mp4).

Запись действующего локального прототипа от 27.10.2026. Разрешение 1920×1080, русские поясняющие титры, без озвучки. Все карты вымышлены.

Последовательность показа:

1. Обзор специалиста и задача приложения.
2. Кабинет пациента, ежедневная отметка и назначенный PHQ-9.
3. Личный дневник и разделение передаваемых сведений.
4. Аналитика специалиста, динамика и условный сценарий.
5. Интерактивная точка графика и исходные ответы.
6. Объяснимые подсказки и отдельный сигнал пункта 9.
7. Расписание, реестр и следующий этап развития.

При записи не создавались новые завершённые опросники и не сохранялась новая отметка дневника. Для связи кабинета с вымышленной картой использован демонстрационный код доступа. Клинические исходы и работа с реальными пациентами не демонстрируются.

Если требуется голос, запись можно использовать как видеоряд: пояснения соответствуют действиям на экране. Подробный текст защиты находится в [заметках к презентации](../pitch/structure-36-slides.md).
